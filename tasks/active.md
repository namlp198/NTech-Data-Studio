# Task đang làm

Module 3 Dataset đã xong phần code và chạy được; Module 1, 2 và 3 còn cần chủ dự án thử trên ảnh thật. Task tiếp theo: Module 4 Export (YOLO26 detect/segment/obb/classify, COCO, validator, nhập nhãn có sẵn). Exporter sinh ảnh tăng cường bằng `RenderPlanner` + `OpenCvAugmentationEngine` + `LabelTransformer`, đọc nhãn hiện tại từ `annotations`, và phải xử lý OBB nhô ra ngoài ảnh (xem `docs/design/screens/DATASET.md`, mục Giới hạn đã biết).
